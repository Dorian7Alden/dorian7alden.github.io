# 2027届暑期实习 — 后端开发（Java方向）招聘要求总结

> 数据来源：牛客网（3份）、Boss直聘（6份）、面经（1份），共覆盖腾讯云、百度、字节跳动、滴滴等企业。

---

## 一、硬技能要求

### 1.1 编程语言

| 语言 | 重要程度 | 说明 |
|------|----------|------|
| **Java** | ★★★★★ | 最主流，几乎所有岗位首选。需深入掌握 JVM、集合、并发、泛型、Stream API（JDK 8+） |
| **Go** | ★★★☆ | 约 50% 岗位要求或接受，增长中台方向尤其看重 |
| C/C++ | ★★☆ | 部分岗位（如腾讯云）要求，作为底层语言基础加分 |
| Python | ★★☆ | 多为加分项，用于脚本、数据处理、AI 方向配合 |

**Java 重点：** 集合框架、泛型、Stream API / Lambda、多线程与锁、JVM 内存模型与 GC、异常处理

### 1.2 主流框架

| 框架 | 重要程度 | 说明 |
|------|----------|------|
| **Spring Boot** | ★★★★★ | 几乎所有 Java 岗位必问，需深入理解自动配置、IOC/AOP、拦截器、定时任务 |
| **Spring Cloud** | ★★★★ | 微服务体系核心，网关、注册中心、配置中心、服务调用、熔断降级 |
| **MyBatis / MyBatis-Plus** | ★★★★ | ORM 框架，SQL 映射、动态 SQL、分页插件 |
| Gin（Go 方向） | ★★☆ | Go 后端框架 |
| Django（Python 方向） | ★☆☆ | 偶尔提及 |

### 1.3 数据库

| 技术 | 重要程度 | 说明 |
|------|----------|------|
| **MySQL** | ★★★★★ | 必问核心：表设计、索引优化（B+Tree）、慢SQL排查、事务隔离级别、MVCC、锁机制 |
| **Redis** | ★★★★★ | 缓存策略、数据结构（String/List/Set/ZSet/Hash）、分布式锁、缓存穿透/击穿/雪崩、持久化 RDB/AOF |
| NoSQL | ★★☆ | 了解 Key-Value 存储原理即可 |

### 1.4 中间件与基础设施

| 技术 | 重要程度 | 说明 |
|------|----------|------|
| **消息队列** | ★★★★ | RocketMQ / Kafka / RabbitMQ 至少熟悉一个，理解异步解耦、削峰填谷、最终一致性、消息可靠投递 |
| **分布式系统** | ★★★★ | CAP 理论、分布式锁、分布式事务、分布式 ID、负载均衡、服务注册与发现 |
| **微服务** | ★★★★ | 服务拆分、API 网关、RPC 调用（Dubbo/gRPC）、熔断限流 |
| **Docker / K8s** | ★★★ | 容器化部署、基本运维（部分岗位加分） |
| **Elasticsearch** | ★★☆ | 搜索场景，部分岗位（如百度爱企查）提及 |

### 1.5 计算机基础（所有岗位必问）

| 领域 | 重点内容 |
|------|----------|
| **数据结构与算法** | 数组、链表、栈、队列、树、图、哈希表、排序、贪心、DP、常见 LeetCode 中等难度 |
| **计算机网络** | TCP/UDP、HTTP/HTTPS、三次握手四次挥手、DNS、CDN、OSI 模型、Cookie/Session |
| **操作系统** | 进程/线程、内存管理、文件系统、Linux 常用命令、Shell 脚本 |
| **设计模式** | 单例、工厂、代理、观察者、策略、模板方法等常见模式 |

### 1.6 工程化能力

- Git 版本控制（分支管理、合并、回滚）
- RESTful API 设计规范
- 单元测试编写
- 日志与链路追踪排查
- Linux 基本操作（文件、权限、进程、网络、日志查看）

## 三、2027届校招新趋势

相比往年，今年招聘要求出现以下几个明显变化：

### 3.1 AI 能力成为加分项 🆕
- **AI Agent / LLM 概念**：部分岗位明确要求"了解 AI Agent 技术基本概念"，愿意学习相关开发
- **AI 编码工具**：越来越多 JD 提到"熟练运用 AI 研发工具"、"会使用 AI 编码工具辅助开发"，同时强调"具备自主校验 AI 输出正确性的意识和基础能力"
- 说明：企业层面已开始将 AI 工具作为日常开发的一部分，但要求候选人不盲目依赖

### 3.2 数据敏感度 🆕
- 部分岗位（增长中台方向）特别强调"数据敏感度"和"数据统计分析能力"
- 与业务结合更紧密，后端不再只是"实现功能"

### 3.3 DDD（领域驱动设计）🆕
- 百度等公司明确提到"熟悉 DDD 开发模式优先"

## 五、面试高频考点（来自面经分析）

根据经纬恒润 Java 开发一面（以及 JD 中反复出现的关键词），整理如下：

### 5.1 项目深挖（最重要，占据面试 60%+ 时间）
- **项目来源**：课程项目还是自学项目？是否独立搭建？
- **技术难点**：遇到过什么难题？怎么解决？为什么选择这个方案？
- **细节追问**：每个技术方案都要能说清楚 "选型理由" 和 "替代方案对比"
- **RBAC 权限模型**：表结构设计、权限校验流程、前端拦截 vs 后端拦截
- **缓存策略**：缓存一致性、缓存失效策略、缓存穿透/击穿/雪崩
- **消息队列**：你为什么选 RocketMQ 而不是 Kafka/RabbitMQ？
- **高并发场景设计**：多线程、缓存、异步——每个环节的失败处理策略
- **分布式事务**：有没有实现？了解哪些方案？（Seata、TCC、可靠消息最终一致性等）

### 5.2 Java 基础
- 泛型（类型擦除、通配符）
- Stream API（JDK 8+ 流式操作）
- 集合（HashMap、ConcurrentHashMap 底层）
- 多线程（线程池、锁升级、volatile、CAS）
- JVM（内存结构、GC 算法、类加载）

### 5.3 框架原理
- Spring Boot 自动配置原理
- Spring IOC / AOP 原理
- MyBatis 执行流程
- 定时任务实现方式（@Scheduled、XXL-Job、Elastic-Job）

### 5.4 系统设计
- 数据库分页查询（深分页问题）
- 接口幂等性设计
- 限流方案（令牌桶、漏桶、滑动窗口）
- 分布式锁（Redis SETNX + Lua、Redisson、ZooKeeper）

## 六、准备建议（按优先级排序）

### Tier 1 — 必须精通（决定性因素）
1. **Java 核心技术栈**：集合、多线程、JVM、Stream/Lambda
2. **Spring Boot + MyBatis**：能独立搭建项目、说清原理
3. **MySQL + Redis**：能写复杂 SQL、设计索引、设计缓存方案
4. **数据结构与算法**：LeetCode 中等难度通过
5. **2-3 个有深度的项目**：能讲清楚架构设计、技术选型和踩坑经历

### Tier 2 — 应该掌握（显著加分）
6. **消息队列**：至少实战过一个，理解使用场景
7. **微服务 / 分布式基础**：注册中心、配置中心、网关、RPC
8. **计算机网络 + 操作系统**：经典八股文，面试必问
9. **Linux + Git**：日常开发工具

### Tier 3 — 锦上添花（体现学习热情）
10. **AI 辅助开发工具使用经验**
11. **DDD、设计模式**
12. **K8s / Docker 运维经验**
13. **技术博客 / GitHub 维护**
14. **Go / Python 第二语言**

## 七、面经复盘教训

> 来自 [7.11 经纬恒润 Java 开发一面](面经/7.11经纬恒润java开发一面.md)

| 教训 | 具体表现 | 改进方向 |
|------|----------|----------|
| **项目细节不够清晰** | 被问到缓存失败处理策略时回答矛盾 | 对所有技术方案都要预演"如果 XX 失败了怎么办" |
| **知识广度不够** | 不知道 Stream API、说不清定时任务方案 | JDK 8+ 新特性、Spring 生态要系统学习 |
| **表达逻辑混乱** | "嗯嗯嗯"、"回答没有逻辑" | 多用 STAR 法则（ Situation-Task-Action-Result ）组织回答 |
| **选型没有对比** | 知道用 RocketMQ 但不知道为什么选它 | 每个技术选择都要有对比分析：A vs B vs C，为什么选 |
| **分布式薄弱** | 没有实现过分布式事务 | 至少了解概念和常见方案，最好有 Demo 落地 |
