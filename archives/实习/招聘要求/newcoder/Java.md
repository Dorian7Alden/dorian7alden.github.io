岗位职责
业务系统开发
使用 Java、Spring Boot、Spring Cloud 等技术完成核心业务模块开发，例如订单、支付、用户、营销、库存、消息推送等模块。
接口设计与开发
负责 RESTful API、RPC 接口的设计与实现，完成前后端、内部服务、第三方系统之间的数据交互。
数据库设计与优化
参与 MySQL 表结构设计，编写 SQL，进行索引优化、慢 SQL 排查、事务控制和数据一致性处理。
缓存与高并发优化
使用 Redis 做缓存、分布式锁、限流、热点数据优化，提升系统并发能力和接口响应速度。
消息队列应用
使用 Kafka、RabbitMQ、RocketMQ 等消息队列实现异步解耦、削峰填谷、延迟任务和最终一致性。
系统稳定性保障
参与线上问题排查，处理接口超时、服务异常、数据库压力、消息堆积等问题，配合监控告警系统保障服务稳定运行。
