### 7 [矩阵置零](https://leetcode.cn/problems/set-matrix-zeroes/)



#### 【原始题目】

给定一个 `m x n` 的矩阵，如果一个元素为 `0`，则将其所在行和列的所有元素都设为 `0`。请使用 **原地** 算法。进阶要求从 `O(mn)` 额外空间优化到仅使用常量空间。

<img src="https://gitee.com/Dorian7Alden/pic-go/raw/master/typora/image-20260731152221522.png" alt="image-20260731152221522" style="zoom:50%;" />

#### 【题目速记】

矩阵中遇到 `0`，则整行整列变 `0`，必须原地完成，不能新建矩阵。

---

#### 【题解】

> 一句话速通：借助两个布尔数组分别记录需要置零的行和列，先遍历标记，再遍历修改。

##### 【算法思想】

- **辅助数组标记**：利用额外的一维布尔数组 `row` 和 `col`，分别记录矩阵中某一行或某一列是否需要置零。

##### 【核心思路】

1. 初始化两个布尔数组 `row` 和 `col`，长度分别为 `m` 和 `n`。
2. 第一次遍历矩阵，若 `matrix[i][j] == 0`，则标记 `row[i] = true`，`col[j] = true`。
3. 第二次遍历矩阵，若当前行或列被标记过（即 `row[i] || col[j]` 为真），则将当前元素置为 `0`。

##### 【复杂度】

- 时间复杂度 $O(mn)$ ：需要完整遍历矩阵两遍。
- 空间复杂度 $O(m + n)$ ：额外使用了两个长度分别为 `m` 和 `n` 的辅助数组。

##### 【伪代码】

```text
初始化 row[m] 和 col[n] 为 false
对于每个元素 matrix[i][j]:
    如果 matrix[i][j] == 0:
        row[i] = true
        col[j] = true

对于每个元素 matrix[i][j]:
    如果 row[i] 或 col[j] 为 true:
        matrix[i][j] = 0
```

##### 【易错点】

- 注意不要在遍历过程中边判断边修改，因为实时修改会导致后续元素错判，必须先**遍历标记**，再**统一修改**。

##### 【完整代码】

```Java
class Solution {
    public void setZeroes(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        boolean[] row = new boolean[m];
        boolean[] col = new boolean[n];
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (matrix[i][j] == 0) {
                    row[i] = true;
                    col[j] = true;
                }
            }
        }
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (row[i] || col[j]) {
                    matrix[i][j] = 0;
                }
            }
        }
    }
}
```

---

#### 【题解】

> 一句话速通：利用矩阵的第一行和第一列作为**原位标记**，先分别记录第一行和第一列本身的原始状态，再进行内部标记与置零。

##### 【算法思想】

- **原地标记**：将第一行和第一列用作哈希/标记存储空间，避免额外数组的开销。

##### 【核心思路】

1. 检查第一行和第一列本身是否存在 `0`，用两个布尔变量 `rowZero` 和 `colZero` 分别记录。
2. 从 `(1,1)` 开始遍历其余元素，如果遇到 `0`，将对应的**首行** `matrix[0][j]` 和**首列** `matrix[i][0]` 都置为 `0`（作为标记）。
3. 再次从 `(1,1)` 开始遍历，检查首行和首列的标记，如果当前元素对应的首行或首列被标记为 `0`，则将此元素置 `0`。
4. 根据 `rowZero` 和 `colZero` 的状态，单独处理第一行和第一列。

##### 【复杂度】

- 时间复杂度 $O(mn)$ ：虽然流程多，但仍然是常数次完整遍历。
- 空间复杂度 $O(1)$ ：只借助了两个布尔变量，符合题目进阶要求。

##### 【伪代码】

```text
遍历第一行，记录是否有 0 到 rowZero
遍历第一列，记录是否有 0 到 colZero

对于 matrix[1..m-1][1..n-1]:
    如果当前元素是 0:
        matrix[i][0] = 0
        matrix[0][j] = 0

对于 matrix[1..m-1][1..n-1]:
    如果 matrix[i][0] == 0 或 matrix[0][j] == 0:
        matrix[i][j] = 0

如果 rowZero 为 true，将第一行全置 0
如果 colZero 为 true，将第一列全置 0
```

##### 【易错点】

- **处理顺序非常关键**：必须先记录第一行和第一列自身的状态，再开始内部标记；最后再根据记录的状态重置第一行和第一列，防止标记被污染。
- 不能一步到位直接把非首行首列的元素置零，要先把标记打在首行首列，再**根据标记统一处理**内部。

##### 【完整代码】

```Java
class Solution {
    public void setZeroes(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        boolean rowZero = false, colZero = false;
        
        // 1. 检查第一行和第一列本身是否有0
        for (int j = 0; j < n; j++) {
            if (matrix[0][j] == 0) rowZero = true;
        }
        for (int i = 0; i < m; i++) {
            if (matrix[i][0] == 0) colZero = true;
        }
        
        // 2. 用首行和首列作为标记数组
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][j] == 0) {
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }
        
        // 3. 根据标记处理内部元素
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                    matrix[i][j] = 0;
                }
            }
        }
        
        // 4. 处理第一行和第一列
        if (rowZero) {
            for (int j = 0; j < n; j++) matrix[0][j] = 0;
        }
        if (colZero) {
            for (int i = 0; i < m; i++) matrix[i][0] = 0;
        }
    }
}
```
