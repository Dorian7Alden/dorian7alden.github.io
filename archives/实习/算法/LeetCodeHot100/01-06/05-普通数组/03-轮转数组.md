### 3 [轮转数组](https://leetcode.cn/problems/rotate-array/)



#### 【原始题目】

给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。要求至少想到三种不同方法，并尝试使用空间复杂度 $O(1)$ 的原地算法。

示例 1：
输入: nums = [1,2,3,4,5,6,7], k = 3
输出: [5,6,7,1,2,3,4]

示例 2：
输入：nums = [-1,-100,3,99], k = 2
输出：[3,99,-1,-100]

#### 【题目速记】

数组向右循环移动 `k` 位。`k` 可能很大，需要对长度取模。考察原地操作、数组翻转或额外数组。

#### 【题解】

> 一句话速通：利用额外数组直接计算每个元素的最终位置，再把结果拷回原数组。

##### 【算法思想】

- 辅助数组：开辟等长数组，根据 `(i + k) % n` 一步定位目标下标，完成移动。

##### 【核心思路】

1. 计算有效偏移量 `k = k % n`，避免多余轮转。
2. 创建新数组 `temp`，遍历原数组，将 `nums[i]` 放到 `temp[(i + k) % n]`。
3. 将 `temp` 中所有元素复制回 `nums`。

##### 【复杂度】

- 时间复杂度 $O(n)$ ：每个元素访问一次。
- 空间复杂度 $O(n)$ ：使用了等长辅助数组。

##### 【伪代码】

```text
n = nums.length
k = k % n
temp = 长度为 n 的新数组
for i = 0 to n-1:
    temp[(i + k) % n] = nums[i]
将 temp 复制回 nums
```

##### 【易错点】

- 忘记 `k % n`，当 `k > n` 时会导致下标越界或错误结果。
- Java 中数组拷贝需用 `System.arraycopy` 或循环赋值。

##### 【完整代码】

```Java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k = k % n;
        int[] temp = new int[n];
        for (int i = 0; i < n; i++) {
            temp[(i + k) % n] = nums[i];
        }
        System.arraycopy(temp, 0, nums, 0, n);
    }
}
```

#### 【题解】

> 一句话速通：用环状替换思想，每次把元素放到最终位置，沿环遍历直到回到起点，通过最大公约数控制起始点数量。

##### 【算法思想】

- 环状替换：按 `(current + k) % n` 的规则形成多个环，依次遍历每个环，实现原地移动。
- 最大公约数：环的个数等于 $gcd(n, k)$ ，用来确定需要多少个起始点。

##### 【核心思路】

1. `k = k % n`，若 `k == 0` 直接返回。
2. 计算 `count = gcd(n, k)`，表示一共需要走 `count` 轮环。
3. 每轮从一个新的起始点出发，用 `prev` 保存被挤出的值，找到其目标位置，交换后继续，直到回到该轮起点。
4. 每放置一个元素，已处理计数加一，当计数达到 `n` 时结束。

##### 【复杂度】

- 时间复杂度 $O(n)$ ：每个元素恰好移动一次。
- 空间复杂度 $O(1)$ ：只使用常数个变量。

##### 【伪代码】

```text
n = nums.length
k = k % n
count = 0
for start = 0 to gcd(n, k) - 1:
    current = start
    prev = nums[start]
    do:
        next = (current + k) % n
        temp = nums[next]
        nums[next] = prev
        prev = temp
        current = next
        count++
    while current != start
```

##### 【易错点】

- 最大公约数计算要正确，否则会陷入死循环或漏掉元素。
- 内层循环是 do-while，确保起点元素被正确放置。
- 注意当 `k == 0` 时无需任何操作。

##### 【完整代码】

```Java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k = k % n;
        if (k == 0) return;
        int count = gcd(n, k);
        for (int start = 0; start < count; start++) {
            int current = start;
            int prev = nums[start];
            do {
                int next = (current + k) % n;
                int temp = nums[next];
                nums[next] = prev;
                prev = temp;
                current = next;
            } while (current != start);
        }
    }
    
    private int gcd(int a, int b) {
        return b == 0 ? a : gcd(b, a % b);
    }
}
```

#### 【题解】

> 一句话速通：三次数组反转，先整体翻转，再分别翻转前 `k` 个和后 `n-k` 个元素，达到原地轮转效果。

##### 【算法思想】

- 数组反转：利用“反转整个数组 + 反转两部分”的组合，实现循环右移。
- 双指针：反转操作可用双指针交换首尾元素完成。

##### 【核心思路】

1. `k = k % n`。
2. 反转整个数组 `[0, n-1]`。
3. 反转前 `k` 个元素 `[0, k-1]`。
4. 反转剩余 `n-k` 个元素 `[k, n-1]`。

##### 【复杂度】

- 时间复杂度 $O(n)$ ：三次遍历，每个元素被访问常数次。
- 空间复杂度 $O(1)$ ：原地反转，仅使用双指针临时变量。

##### 【伪代码】

```text
reverse(nums, 0, n-1)
reverse(nums, 0, k-1)
reverse(nums, k, n-1)
```

##### 【易错点】

- 取模 `k %= n` 必不可少，否则反转区间会越界。
- 反转函数中注意传入正确的左右边界，`k-1` 和 `k` 分别是两段的分界。
- 当 `k == 0` 时调用反转仍正确，但可提前返回节省时间。

##### 【完整代码】

```Java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k = k % n;
        reverse(nums, 0, n - 1);
        reverse(nums, 0, k - 1);
        reverse(nums, k, n - 1);
    }
    
    private void reverse(int[] nums, int left, int right) {
        while (left < right) {
            int temp = nums[left];
            nums[left] = nums[right];
            nums[right] = temp;
            left++;
            right--;
        }
    }
}
```
