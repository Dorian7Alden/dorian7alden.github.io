### 1 [最大子数组和](https://leetcode.cn/problems/maximum-subarray/)



#### 【原始题目】

给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

子数组是数组中的一个连续部分。

**示例：**
```
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大，为 6 。
```

**提示：**
- $1 \le nums.length \le 10^5$
- $-10^4 \le nums[i] \le 10^4$

**进阶：** 尝试使用分治法求解。

#### 【题目速记】

- 给一个整数数组，元素可正可负。
- 要找一段**连续**子数组，使得元素和最大，返回这个最大和。
- 数组长度可达十万，必须 $O(n)$ 或 $O(n \log n)$。

#### 【题解】

> 一句话速通：动态规划（Kadane 算法），维护以当前元素结尾的最大子数组和，要么接在前面的子数组后面，要么自己单干，一路更新全局最大值。

##### 【算法思想】

- 动态规划：定义 $dp[i]$ 为以 `nums[i]` 结尾的最大子数组和，利用 $dp[i-1]$ 递推。
- 空间优化：只用一个变量 `pre` 代替 `dp` 数组，滚动更新，将空间降到 $O(1)$。

##### 【核心思路】

1. 初始化 `pre = 0` 表示走到前一个位置时的最大结尾和，`maxAns = nums[0]` 记录全局最大。
2. 遍历每个数 `x`：
   - 决定是否拼接：`pre = max(pre + x, x)`。
   - 用 `pre` 更新全局最大 `maxAns = max(maxAns, pre)`。
3. 返回 `maxAns`。

##### 【复杂度】

- 时间复杂度 $O(n)$ ：只遍历一次数组。
- 空间复杂度 $O(1)$ ：只用两个变量。

##### 【伪代码】

```text
function maxSubArray(nums):
    pre = 0
    maxAns = nums[0]
    for x in nums:
        pre = max(pre + x, x)
        maxAns = max(maxAns, pre)
    return maxAns
```

##### 【易错点】

- 初始化 `maxAns` 必须为 `nums[0]`，不能为 0，否则遇到全负数组会返回 0 而错误。
- 遍历时 `pre` 的更新顺序不能反，必须先用旧 `pre` 计算新 `pre`，再更新 `maxAns`。
- 不要误写成 `pre = max(pre, pre + x)`，那样相当于可以丢弃前面的所有元素，不符合连续子数组要求。

##### 【完整代码】

```Java
class Solution {
    public int maxSubArray(int[] nums) {
        int pre = 0;
        int maxAns = nums[0];
        for (int x : nums) {
            // 要么接在前面子数组后面，要么自己单独开始
            pre = Math.max(pre + x, x);
            maxAns = Math.max(maxAns, pre);
        }
        return maxAns;
    }
}
```

#### 【题解】

> 一句话速通：分治法，把数组分成左右两半，最大子数组要么全在左半、全在右半，要么跨越中点，递归求解左右，再计算跨越中点的最大和，三者取最大。

##### 【算法思想】

- 分治法：将区间 `[l, r]` 递归分成两半，最大子数组和要么来自左子区间、右子区间，要么由横跨中点 `mid` 的左右两部分拼接而成。
- 辅助结构：递归返回一个四元组 `(sum, lMax, rMax, max)`，分别表示区间总和、从左端点开始的最大子段和、以右端点结尾的最大子段和、区间内的最大子段和，用于合并。

##### 【核心思路】

1. 若区间长度为 1，返回四个相同值 `(nums[l], nums[l], nums[l], nums[l])`。
2. 递归获得左子区间 `L` 和右子区间 `R` 的信息。
3. 合并：
   - 区间总和：`sum = L.sum + R.sum`。
   - 从左端开始的最大和：`lMax = max(L.lMax, L.sum + R.lMax)`。
   - 以右端结尾的最大和：`rMax = max(R.rMax, R.sum + L.rMax)`。
   - 区间最大子段和：`max = max(L.max, R.max, L.rMax + R.lMax)`。
4. 最终返回整体的 `max`。

##### 【复杂度】

- 时间复杂度 $O(n \log n)$ ：每层合并 $O(n)$，共 $\log n$ 层。
- 空间复杂度 $O(\log n)$ ：递归栈深度。

##### 【伪代码】

```text
function maxSubArray(nums):
    return divide(nums, 0, len-1).max

function divide(nums, l, r):
    if l == r:
        return (nums[l], nums[l], nums[l], nums[l])
    mid = (l + r) // 2
    L = divide(nums, l, mid)
    R = divide(nums, mid+1, r)
    sum = L.sum + R.sum
    lMax = max(L.lMax, L.sum + R.lMax)
    rMax = max(R.rMax, R.sum + L.rMax)
    maxVal = max(L.max, R.max, L.rMax + R.lMax)
    return (sum, lMax, rMax, maxVal)
```

##### 【易错点】

- 跨越中点的最大和是 `L.rMax + R.lMax`，必须保证左以 `mid` 结尾、右从 `mid+1` 开始，这样才连续。
- 递归基（`l == r`）的四个值要正确赋值，四个值都是该元素本身。
- 合并时的 `lMax` 与 `rMax` 的计算方式不对称，容易写反，注意左子区间的左起最大和可能延伸到右子区间，右子区间的右端结尾最大和可能延伸到左子区间。

##### 【完整代码】

```Java
class Solution {
    // 辅助类，存储四个信息
    private static class Info {
        int sum;   // 区间总和
        int lMax;  // 从左端点开始的最大子段和
        int rMax;  // 以右端点结尾的最大子段和
        int max;   // 区间最大子段和
        Info(int s, int l, int r, int m) {
            sum = s; lMax = l; rMax = r; max = m;
        }
    }
    
    public int maxSubArray(int[] nums) {
        return divide(nums, 0, nums.length - 1).max;
    }
    
    private Info divide(int[] nums, int l, int r) {
        if (l == r) {
            int v = nums[l];
            return new Info(v, v, v, v);
        }
        int mid = (l + r) >>> 1;
        Info L = divide(nums, l, mid);
        Info R = divide(nums, mid + 1, r);
        int sum = L.sum + R.sum;
        int lMax = Math.max(L.lMax, L.sum + R.lMax);
        int rMax = Math.max(R.rMax, R.sum + L.rMax);
        int max = Math.max(Math.max(L.max, R.max), L.rMax + R.lMax);
        return new Info(sum, lMax, rMax, max);
    }
}
```
