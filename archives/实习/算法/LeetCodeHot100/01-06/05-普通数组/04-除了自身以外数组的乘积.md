### 4 [除了自身以外数组的乘积](https://leetcode.cn/problems/product-of-array-except-self/)



#### 【原始题目】

给你一个整数数组 `nums`，返回数组 `answer`，其中 `answer[i]` 等于 `nums` 中除了 `nums[i]` 之外其余各元素的乘积。  
题目保证乘积在 32 位整数范围内。  
**不要使用除法**，且在 $O(n)$ 时间复杂度内完成。

#### 【题目速记】

求每个位置除自己外所有元素的乘积。不能除法、要 $O(n)$。本质是“前缀积 × 后缀积”。

#### 【题解】

> 一句话速通：用两个辅助数组分别记录每个位置的左侧乘积和右侧乘积，最后对应相乘得到结果。

##### 【算法思想】

- 前缀积：记录每个位置左侧所有元素的乘积，避免重复计算
- 后缀积：记录每个位置右侧所有元素的乘积
- 结果拼接：answer[i] = left[i] × right[i]

##### 【核心思路】

1. 创建 `left` 数组，`left[i]` 表示 `nums[i]` 左侧所有元素的乘积（不包含 `nums[i]`）
2. 创建 `right` 数组，`right[i]` 表示 `nums[i]` 右侧所有元素的乘积
3. 遍历一次，`answer[i] = left[i] * right[i]`，得到最终结果

##### 【复杂度】

- 时间复杂度 $O(n)$ ：三次线性遍历
- 空间复杂度 $O(n)$ ：额外使用了 left 和 right 两个数组

##### 【伪代码】

```text
初始化 left[n], right[n]
left[0] = 1
for i = 1 to n-1:
    left[i] = left[i-1] * nums[i-1]

right[n-1] = 1
for i = n-2 down to 0:
    right[i] = right[i+1] * nums[i+1]

for i = 0 to n-1:
    answer[i] = left[i] * right[i]
返回 answer
```

##### 【易错点】

- `left[0]` 和 `right[n-1]` 初始值必须为 1，不是 0
- 注意边界：左侧乘积不包含当前元素，指针偏移要正确

##### 【完整代码】

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] left = new int[n];
        int[] right = new int[n];
        int[] answer = new int[n];

        // 左侧乘积
        left[0] = 1;
        for (int i = 1; i < n; i++) {
            left[i] = left[i - 1] * nums[i - 1];
        }

        // 右侧乘积
        right[n - 1] = 1;
        for (int i = n - 2; i >= 0; i--) {
            right[i] = right[i + 1] * nums[i + 1];
        }

        // 合并
        for (int i = 0; i < n; i++) {
            answer[i] = left[i] * right[i];
        }

        return answer;
    }
}
```

#### 【题解】

> 一句话速通：把输出数组直接当作左乘积数组，再动态维护一个右侧乘积变量，从右往左乘进去，实现 $O(1)$ 额外空间。

##### 【算法思想】

- 输出数组复用：先存储左侧乘积，省掉一个数组
- 动态后缀变量：用一个变量 `right` 从右向左滚动，逐步累乘右侧乘积并更新结果
- 空间优化：只使用输出数组和常数个变量

##### 【核心思路】

1. 第一遍从左到右：`answer[i]` 存 `nums[i]` 左侧所有元素的乘积
2. 第二遍从右到左：用一个变量 `right` 记录右侧累积乘积，每一步把 `right` 乘进 `answer[i]`，然后更新 `right *= nums[i]`
3. 结束后 `answer` 就是最终结果

##### 【复杂度】

- 时间复杂度 $O(n)$ ：遍历两次数组
- 空间复杂度 $O(1)$ ：除输出数组外，只用了常数个变量

##### 【伪代码】

```text
answer[n]  // 作为输出数组
answer[0] = 1
for i = 1 to n-1:
    answer[i] = answer[i-1] * nums[i-1]

right = 1
for i = n-1 down to 0:
    answer[i] = answer[i] * right
    right = right * nums[i]
返回 answer
```

##### 【易错点】

- 从右向左遍历时，一定要先乘 `right` 再更新 `right`，否则当前元素会被提前乘入
- 输出数组不算额外空间，所以用 `answer` 直接做左乘积数组完全合理

##### 【完整代码】

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] answer = new int[n];

        // 先存放左侧乘积
        answer[0] = 1;
        for (int i = 1; i < n; i++) {
            answer[i] = answer[i - 1] * nums[i - 1];
        }

        // 从右向左乘入右侧乘积
        int right = 1;
        for (int i = n - 1; i >= 0; i--) {
            answer[i] = answer[i] * right;
            right *= nums[i];
        }

        return answer;
    }
}
```
