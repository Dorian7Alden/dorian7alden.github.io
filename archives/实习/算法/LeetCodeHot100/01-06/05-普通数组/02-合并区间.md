### 2 [合并区间](https://leetcode.cn/problems/merge-intervals/)



#### 【原始题目】

以数组 `intervals` 表示若干个区间的集合，其中单个区间为 `intervals[i] = [start_i, end_i]`。请你合并所有重叠的区间，并返回一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间。

示例：
输入：`intervals = [[1,3],[2,6],[8,10],[15,18]]`
输出：`[[1,6],[8,10],[15,18]]`
解释：区间 `[1,3]` 和 `[2,6]` 重叠，合并为 `[1,6]`。

#### 【题目速记】

给一堆区间，把有重叠的合并成一个大区间，返回所有合并后不重叠的区间。重叠判断：两个区间只要 `start <= end` 另一区间的 `start` 就认为重叠。

#### 【题解】

> 一句话速通：按区间起点排序后，用一个列表存结果，依次判断当前区间是否与结果列表最后一个区间重叠，能合并就扩张右边界，不能就新增区间。

##### 【算法思想】

- 排序：将区间按左端点升序排列，保证可能重叠的区间在数组中相邻。
- 贪心合并：只需要跟结果集中最后一个区间比较，因为左端点已经有序，后续区间的左端点一定不小于前面区间的左端点，跨区间重叠不可能发生。

##### 【核心思路】

1. 对 `intervals` 按每个区间的左端点排序（`Arrays.sort` + 比较器）。
2. 准备一个结果列表（可用 `List<int[]>` 存合并后的区间）。
3. 遍历排序后的区间，对每个区间 `curr`：
   - 若结果列表为空，或 `curr` 的左端点 **大于** 结果列表最后一个区间的右端点，说明无重叠，直接把 `curr` 加入结果。
   - 否则有重叠，将结果列表最后一个区间的右端点更新为 `max(最后一个区间的右端点, curr的右端点)`。
4. 遍历结束，把结果列表转成 `int[][]` 返回。

##### 【复杂度】

- 时间复杂度 $O(n \log n)$ ：排序需要 $O(n \log n)$ ，合并只需一次线性遍历 $O(n)$ 。
- 空间复杂度 $O(n)$ ：结果列表需要存储合并后的区间，最坏情况下所有区间都不重叠，占用 $O(n)$ 。

##### 【伪代码】

```text
function merge(intervals):
    if intervals is empty: return empty array
    
    按区间左端点排序 intervals
    初始化 List<int[]> merged
    
    for each 区间 curr in intervals:
        if merged 为空 or merged最后一个区间的右端点 < curr左端点:
            将 curr 加入 merged
        else:
            用 curr右端点 更新 merged最后一个区间的右端点（取较大值）
    
    return merged 转为二维数组
```

##### 【易错点】

- 排序时只按左端点，不要加右端点排序条件，否则会打乱合并逻辑。
- 合并时注意边界情况：两个区间恰好端点相接（`[1,4]` 和 `[4,5]`）也属于重叠，判断要用 `<` 还是 `<=`，此处 `左端点 > 右端点` 才不重叠，所以用 `merged.getLast()[1] < curr[0]` 作为不重叠条件。
- 更新右端点时要取 `Math.max`，不能直接赋值，因为可能出现完全包含的关系（如 `[1,10]` 和 `[2,6]`），此时右端点不应缩小。

##### 【完整代码】

```Java
class Solution {
    public int[][] merge(int[][] intervals) {
        if (intervals == null || intervals.length == 0) {
            return new int[0][0];
        }
        
        // 1. 按区间左端点排序
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));
        
        // 2. 准备结果列表
        List<int[]> merged = new ArrayList<>();
        
        // 3. 遍历并合并
        for (int[] curr : intervals) {
            // 如果结果列表为空 或 当前区间左端点 > 结果最后一个区间的右端点，不重叠，直接加入
            if (merged.isEmpty() || merged.get(merged.size() - 1)[1] < curr[0]) {
                merged.add(curr);
            } else {
                // 重叠，更新右端点为两者的较大值
                int[] last = merged.get(merged.size() - 1);
                last[1] = Math.max(last[1], curr[1]);
            }
        }
        
        // 4. 转成二维数组返回
        return merged.toArray(new int[merged.size()][]);
    }
}
```
