### 5 [缺失的第一个正数](https://leetcode.cn/problems/first-missing-positive/)



#### 【原始题目】

给你一个未排序的整数数组 `nums`，请你找出其中没有出现的最小的正整数。

要求：时间复杂度 $O(n)$，只使用常数级别额外空间。

**示例 1：**  
输入：`nums = [1,2,0]`  
输出：`3`  

**示例 2：**  
输入：`nums = [3,4,-1,1]`  
输出：`2`  

**示例 3：**  
输入：`nums = [7,8,9,11,12]`  
输出：`1`  

**提示：**  
- `1 <= nums.length <= 10^5`  
- `-2^31 <= nums[i] <= 2^31 - 1`

#### 【题目速记】

无序数组，找第一个缺失的正整数。关键：长度 `n`，答案必在 $[1, n+1]$ 之间。要用 $O(n)$ 时间、$O(1)$ 空间，必须原地借用数组本身当哈希表。

#### 【题解】

> 一句话速通：通过循环交换，把值在 $[1, n]$ 内的数放到索引 `值-1` 的位置，然后扫描找第一个下标 `i` 处不是 `i+1` 的位置，返回 `i+1`；全正确则返回 `n+1`。

##### 【算法思想】

- 原地哈希：数组下标直接映射为数字 `索引+1`，在常数空间下实现快速存在性判断。
- 循环排序思想：不断将当前数字交换到它该在的位置，直到不需要交换为止。

##### 【核心思路】

1. 遍历每个位置 `i`，只要 `nums[i]` 在 $[1, n]$ 范围内，并且目标位置 `nums[i]-1` 上的数不是 `nums[i]`，就交换两者。
2. 完成交换后，所有“有用的数”都各就各位。
3. 再次遍历，第一个 `nums[i] != i+1` 的 `i` 就对应缺失的最小正整数 `i+1`。
4. 若全部正确，说明 $1$ 到 $n$ 都存在，缺失的是 `n+1`。

##### 【复杂度】

- 时间复杂度 $O(n)$：每个数最多被交换一次到正确位置，内层 `while` 总交换次数不超过 $n$。
- 空间复杂度 $O(1)$：只用原数组，没有额外空间。

##### 【伪代码】

```text
n = nums.length
for i = 0 to n-1:
    while 1 <= nums[i] <= n and nums[nums[i]-1] != nums[i]:
        swap(nums[i], nums[nums[i]-1])
for i = 0 to n-1:
    if nums[i] != i+1:
        return i+1
return n+1
```

##### 【易错点】

- 交换条件必须包含 `nums[nums[i]-1] != nums[i]`，否则遇到重复数字会死循环。
- 交换时注意先取目标索引 `idx = nums[i] - 1`，再交换，防止数组越界。
- 负数、0、大于 `n` 的数直接跳过，不用处理。

##### 【完整代码】

```Java
class Solution {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;
        // 将每个数字放到它应在的位置：值 x 放到下标 x-1
        for (int i = 0; i < n; i++) {
            while (nums[i] >= 1 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
                // 交换 nums[i] 和 nums[nums[i] - 1]
                int temp = nums[nums[i] - 1];
                nums[nums[i] - 1] = nums[i];
                nums[i] = temp;
            }
        }
        // 找出第一个位置 i 不是 i+1 的数
        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) {
                return i + 1;
            }
        }
        return n + 1;
    }
}
```

#### 【题解】

> 一句话速通：先把无用数字（≤0 或 >n）都改成 `n+1`，然后遍历数组，用负号标记以数字为下标的对应位置，表示该数字出现过，最后找第一个保持正数的位置，索引+1 即为答案。

##### 【算法思想】

- 原地标记：利用数组本身记录存在性，借助正负号区分“出现过”和“没出现过”。
- 预处理过滤：将越界或无用的数字统一替换为不影响符号判断的哨兵值 `n+1`。

##### 【核心思路】

1. 第一次遍历，将所有 `≤0` 或 `>n` 的元素改为 `n+1`（此时所有元素都为正数）。
2. 第二次遍历，取当前元素的绝对值 `num = |nums[i]|`，如果 `1 ≤ num ≤ n`，就把 `nums[num-1]` 设为负值（若已为负则保持负），表示数字 `num` 存在。
3. 第三次遍历，找到第一个 `nums[i] > 0` 的索引 `i`，说明 `i+1` 没出现过，返回 `i+1`。
4. 若全为负数，返回 `n+1`。

##### 【复杂度】

- 时间复杂度 $O(n)$：三次遍历，每次都是线性。
- 空间复杂度 $O(1)$：原地操作。

##### 【伪代码】

```text
n = nums.length
for i = 0 to n-1:
    if nums[i] <= 0 or nums[i] > n:
        nums[i] = n + 1
for i = 0 to n-1:
    num = |nums[i]|
    if 1 <= num <= n:
        nums[num-1] = -|nums[num-1]|
for i = 0 to n-1:
    if nums[i] > 0:
        return i + 1
return n + 1
```

##### 【易错点】

- 第二次遍历时一定要取绝对值，因为有些位置可能已被标记为负。
- 标记时必须 `-Math.abs(nums[num-1])`，避免被二次取负变为正数。
- 预处理改成 `n+1` 是为了不影响符号判断，如果改成 0 或负数会干扰后续逻辑。

##### 【完整代码】

```Java
class Solution {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;
        // 1. 将无用数字改为 n+1
        for (int i = 0; i < n; i++) {
            if (nums[i] <= 0 || nums[i] > n) {
                nums[i] = n + 1;
            }
        }
        // 2. 用负号标记出现过的数字
        for (int i = 0; i < n; i++) {
            int num = Math.abs(nums[i]);
            if (num >= 1 && num <= n) {
                nums[num - 1] = -Math.abs(nums[num - 1]);
            }
        }
        // 3. 找出第一个正数
        for (int i = 0; i < n; i++) {
            if (nums[i] > 0) {
                return i + 1;
            }
        }
        return n + 1;
    }
}
```
