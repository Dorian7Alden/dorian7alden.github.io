## 遇到的问题
+ 变量重名：很多单字母变量，可能会重复赋值，导致逻辑出错
+ 变量作用域：当全局变量用函数封装的时候，作用域不同可能导致代码报错。注意变量声明方式
+ 时间戳传递：传递参数的时候，注意时间戳的值
+ 不必要的爬取：找到加密的核心位置。从加密的那**一个**方法方法往上推，可以直接固定的就直接用，避免一些不必要的，很复杂的抓取，增大工程量，然后对加密也没什么作用，就是处理数据的过程。
+ **抓取对象**：分析一下需要获取的方法，类似于“doSignature()”这个方法，可能是封装好的一个加密库的某个方法，抓取过程十分复杂，但是直接抓取整个对象就可以避免还原**加密算法**。

## SM 算法介绍
+ <font style="color:rgb(51, 51, 51);">国产加密算法，这其中就包括 </font>`<font style="color:rgb(51, 51, 51);background-color:rgb(248, 248, 248);">SM1、SM2、SM3 、SM4、SM7、SM9、ZUC</font>`<font style="color:rgb(51, 51, 51);">（祖冲之加密算法）等</font>
+ `<font style="color:rgb(51, 51, 51);background-color:rgb(248, 248, 248);">SM</font>`<font style="color:rgb(51, 51, 51);"> 代表商密，即商业密码，是指用于商业的、不涉及国家秘密的密码技术。</font>

### <font style="color:rgb(51, 51, 51);">SM2 椭圆曲线公钥加密算法</font>
`<font style="color:rgb(51, 51, 51);background-color:rgb(248, 248, 248);">SM2</font>`<font style="color:rgb(51, 51, 51);"> 为椭圆曲线（</font>`<font style="color:rgb(51, 51, 51);background-color:rgb(248, 248, 248);">ECC</font>`<font style="color:rgb(51, 51, 51);">）公钥加密算法，</font>**<font style="color:rgb(51, 51, 51);">非对称加密</font>**<font style="color:rgb(51, 51, 51);">，</font>`<font style="color:rgb(51, 51, 51);background-color:rgb(248, 248, 248);">SM2</font>`<font style="color:rgb(51, 51, 51);"> 算法和 </font>`<font style="color:rgb(51, 51, 51);background-color:rgb(248, 248, 248);">RSA</font>`<font style="color:rgb(51, 51, 51);">算法都是公钥加密算法，</font>`<font style="color:rgb(51, 51, 51);background-color:rgb(248, 248, 248);">SM2</font>`<font style="color:rgb(51, 51, 51);"> 算法是一种更先进安全的算法，在我们国家商用密码体系中被用来替换</font>`<font style="color:rgb(51, 51, 51);background-color:rgb(248, 248, 248);">RSA</font>`<font style="color:rgb(51, 51, 51);"> 算法，在不少官方网站会见到此类加密算法。我国学者对椭圆曲线密码的研究从 20 世纪 80 年代开始，目前已取得不少成果，</font>`<font style="color:rgb(51, 51, 51);background-color:rgb(248, 248, 248);">SM2</font>`<font style="color:rgb(51, 51, 51);"> 椭圆曲线公钥密码算法比 </font>`<font style="color:rgb(51, 51, 51);background-color:rgb(248, 248, 248);">RSA</font>`<font style="color:rgb(51, 51, 51);">算法有以下优势：</font>

| | **<font style="color:rgb(51, 51, 51);">SM2</font>** | **<font style="color:rgb(51, 51, 51);">RSA</font>** |
| --- | --- | --- |
| <font style="color:rgb(51, 51, 51);">安全性</font> | <font style="color:rgb(51, 51, 51);">256 位 SM2 强度已超过 RSA-2048</font> | <font style="color:rgb(51, 51, 51);">一般</font> |
| <font style="color:rgb(51, 51, 51);">算法结构</font> | <font style="color:rgb(51, 51, 51);">基本椭圆曲线（ECC）</font> | <font style="color:rgb(51, 51, 51);">基于特殊的可逆模幂运算</font> |
| <font style="color:rgb(51, 51, 51);">计算复杂度</font> | <font style="color:rgb(51, 51, 51);">完全指数级</font> | <font style="color:rgb(51, 51, 51);">亚指数级</font> |
| <font style="color:rgb(51, 51, 51);">存储空间（密钥长度）</font> | <font style="color:rgb(51, 51, 51);">192-256 bit</font> | <font style="color:rgb(51, 51, 51);">2048-4096 bit</font> |
| <font style="color:rgb(51, 51, 51);">秘钥生成速度</font> | <font style="color:rgb(51, 51, 51);">较 RSA 算法快百倍以上</font> | <font style="color:rgb(51, 51, 51);">慢</font> |
| <font style="color:rgb(51, 51, 51);">解密加密速度</font> | <font style="color:rgb(51, 51, 51);">较快</font> | <font style="color:rgb(51, 51, 51);">一般</font> |




### <font style="color:rgb(51, 51, 51);">SM4 分组加密算法</font>
`<font style="color:rgb(51, 51, 51);background-color:rgb(248, 248, 248);">SM4</font>`<font style="color:rgb(51, 51, 51);"> 为无线局域网标准的分组加密算法，</font>**<font style="color:rgb(51, 51, 51);">对称加密</font>**<font style="color:rgb(51, 51, 51);">，用于替代 </font>`<font style="color:rgb(51, 51, 51);background-color:rgb(248, 248, 248);">DES/AES</font>`<font style="color:rgb(51, 51, 51);"> 等国际算法，</font>`<font style="color:rgb(51, 51, 51);background-color:rgb(248, 248, 248);">SM4</font>`<font style="color:rgb(51, 51, 51);"> 算法与 </font>`<font style="color:rgb(51, 51, 51);background-color:rgb(248, 248, 248);">AES</font>`<font style="color:rgb(51, 51, 51);">算法具有相同的密钥长度和分组长度，均为 128 位，故对消息进行加解密时，若消息长度过长，需要进行分组，要消息长度不足，则要进行填充。加密算法与密钥扩展算法都采用 32 轮非线性迭代结构，解密算法与加密算法的结构相同，只是轮密钥的使用顺序相反，解密轮密钥是加密轮密钥的逆序。</font>

| | **<font style="color:rgb(51, 51, 51);">SM4</font>** | **<font style="color:rgb(51, 51, 51);">DES</font>** | **<font style="color:rgb(51, 51, 51);">AES</font>** |
| --- | --- | --- | --- |
| <font style="color:rgb(51, 51, 51);">计算轮数</font> | <font style="color:rgb(51, 51, 51);">32</font> | <font style="color:rgb(51, 51, 51);">16（3DES 为 16*3）</font> | <font style="color:rgb(51, 51, 51);">10/12/14</font> |
| <font style="color:rgb(51, 51, 51);">密码部件</font> | <font style="color:rgb(51, 51, 51);">S 盒、非线性变换、线性变换、合成变换</font> | <font style="color:rgb(51, 51, 51);">标准算术和逻辑运算、先替换后置换，不含线性变换</font> | <font style="color:rgb(51, 51, 51);">S 盒、行移位变换、列混合变换、圈密钥加变换（AddRoundKey）</font> |

```javascript
// 非对称
var sm2 = require("sm-crypto").sm2

// 生成密钥
var keydata = sm2.generateKeyPairHex();
var publicKey = keydata.publicKey;
var privateKey = keydata.privateKey;

var data = "Python"
var enc_data = sm2.doEncrypt(data, publicKey, 1)
var dec_data = sm2.doDecrypt(enc_data, privateKey, 1)

console.log("enc_data: ", enc_data)
console.log("dec_data: ", dec_data)
```

```javascript
// 对称加密
var sm4 = require("sm-crypto").sm4
// 设置SM4密钥（128位，16字节）
const key = "0123456789ABCDEF0123456789ABCDEF"
// 设置SM4加解密模式（ecb、cbc、ctr等通用模式）
const mode = "ecb"

// 加密
const plaintext = "hello sm4"
const ciphertext = sm4.encrypt(plaintext, key, {mode})
console.log("encrypted: ", ciphertext);

// 解密
const decryptedText = sm4.decrypt(ciphertext, key, {mode})
console.log("decrypted: ", decryptedText);
```
