## Daily English Dictation 90 - intermedia



### 🎧 Listening Practice



**My listening**:

```
1896, the first modern Olympic games opended at the Greece. Land the inter games atheletes fourteen countries.
```

**Answer**:

```
1896. The first modern Olympic Games open in Athens, Greece -- land of the ancient games -- with athletes from 14 countries.
```

**Pronunciation**:

- wi<u>th a</u>thletes

- fourteen => teen is t sound ⬆️
- forty => ty is d sound ⬇️
