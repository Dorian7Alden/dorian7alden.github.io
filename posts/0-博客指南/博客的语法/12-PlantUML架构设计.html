12-PlantUML 架构设计 ​

博客集成 PlantUML 官方编码与矢量解析引擎，支持使用经典 PlantUML 语法描述复杂的分布式系统时序与组件拓扑。

1. 核心特性 ​

  • 矢量渲染：经由服务端安全编码后，即时拉取高清矢量 SVG 展现。
  • 排版隔离：支持使用单色风格，完美融入极简现代化文档版面。
  • 交互式画布工具：鼠标悬浮时展示画布调节工具栏，支持放大、缩小、重置比例、拖拽移动画布以及全屏沉浸式阅读。
  • 双模式图表切换与防过时机制：支持使用 ' @alt: ... 或 [alt="..."] 声明可选精美图片；系统默认优先展示精美图并提供动态图切换，同时计算代码摘要哈希进行版本比对。

2. 时序与协作设计图 ​

源代码：

Markdown
```plantuml
@startuml
skinparam monochrome true
skinparam defaultFontName sans-serif

actor "运维工程师" as Ops
participant "CI 流程" as CI
participant "镜像仓库" as Registry
participant "Kubernetes 集群" as K8s

Ops -> CI: 提交主分支代码
activate CI
CI -> CI: 执行静态检查与单元测试
CI -> Registry: 构建并推送容器镜像
CI -> K8s: 应用滚动更新配置
activate K8s
K8s -> K8s: 启动新实例并通过探针
K8s --> CI: 确认部署健康状态
deactivate K8s
CI --> Ops: 发送发布成功通知
deactivate CI
@enduml
```
