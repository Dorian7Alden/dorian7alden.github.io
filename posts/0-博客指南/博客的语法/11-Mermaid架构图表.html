11-Mermaid 架构图表 ​

博客内置 Mermaid 渲染引擎，支持使用纯文本直接绘制流程图、时序图、状态图等，并自动适配深色与浅色主题。

1. 核心特性 ​

  • 矢量渲染：自动在客户端将图表脚本水合编译为清晰矢量 SVG。
  • 主题联动：无缝联动白天与黑夜模式，切换主题时自动适配线条与文字配色。
  • 交互式画布工具：鼠标悬浮于图表卡片上方时，右上角自动浮现专属控制工具栏，支持放大、缩小、重置原始比例、鼠标按住平移拖拽画布以及全屏沉浸式检视。
  • 双模式图表切换：当算法自动渲染的图表线条复杂或可读性欠佳时，支持配置可选的精美手绘或设计图进行替代展示；博客优先展示精美图，并在右上角提供实时双模式切换开关。
  • 图版本与摘要防过时校验：可选替代图由于是静态图片，无法随源码变更自动调整，存在版本脱节弊端。系统内置了源码哈希计算机制，当图源码修改导致摘要哈希不匹配时，自动显示警示徽标提示作者及时更新替代图。

2. 架构流程图 ​

源代码：

Markdown

    AuthFilter -->|是: 附加上下文| UserSvc[业务核心服务]
    AuthFilter -->|否: 401 拦截| Reject[拒绝访问]
    UserSvc -->|3. 查询缓存| Redis[(Redis 集群)]
    UserSvc -->|4. 事务持久化| DB[(PostgreSQL 数据库)]
```

4. 双模式图表切换与防过时校验 ​

通过代码块标题中括号 [标题\|alt="图片路径" hash="哈希值"] 或在图表源码首行添加 %% @alt: 图片路径 注释，即可为图表绑定可选的精美替代图片。系统会优先展示该精美图，并在右上角提供模式切换按钮。

    Gateway->>Service[业务服务]: 2. 鉴权通过路由转发
    Service-->>Client[客户端 App]: 3. 响应业务处理结果
```
