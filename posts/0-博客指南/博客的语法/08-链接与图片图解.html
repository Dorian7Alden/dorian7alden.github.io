2. 内链链接与双链语法 ​

博客深度支持面向知识库与笔记体系的内链互联与双向链接语法，帮助在文档之间建立网状知识互联结构。

  • 双链语法：直接书写 [[文档名]] 或 [[文档名\|自定义显示文本]]。系统在编译构建时自动寻址目标文章的真实路由，并自动提取渲染对应的文章标题，无需手动编写冗长的层级相对路径。
  • 相对路径内链自动补全：支持原生的 Markdown 相对路径链接。若省略中括号内的文本直接书写 [](./01-标题与大纲层级.md)，系统会自动提取并渲染该目标文档的真实物理标题。
  • 悬浮卡片即时预览：将鼠标悬停在任意内链或双链链接上方时，屏幕会自动弹出一个精美的文档预览小窗口，展示目标文章的所属分类、发布时间、文章标题、摘要片段以及预计阅读时间。
  • 无缝快速跳转：点击预览卡片或内链链接，即可通过客户端路由快速定位跳转至目标文章。

源代码：

Markdown
- 双链默认标题渲染：[[01-标题与大纲层级]]
- 双链自定义别名渲染：[[01-标题与大纲层级|大纲与标题层级规范]]
- 相对链接自动填充标题：[](./05-代码块与高亮体系.md)
- 相对链接自定义文本：[查看代码块配置规范](./05-代码块与高亮体系.md)

  • 高内聚自包含：插图与文档物理聚合，在 Typora、VS Code、Obsidian 等本地编辑器中直接可见，目录迁移时不丢失依赖。

5. 图片内容说明与图解注释 ​

图片属于二进制文件，程序、自动化脚本与大模型在处理 Markdown 文档时无法直接感知其视觉内容。若每次都需要调用多模态视觉模型进行重新分析，开销昂贵且耗时不可控。通过为图片补充内容注释说明，将二进制信息沉淀为结构化文本，程序可以直接读取该说明快速判断图表信息是否完备、是否有必要再次调用视觉模型，彻底打破图片的信息黑盒。

  • 声明方式一：标题参数扩展：在原生 Markdown 图片的 title 字段中使用 desc: 详细说明 或 说明: 详细说明 进行标注，例如 ![架构示意图](./assets/local-diagram.svg "系统拓扑 \| desc: 展示客户端到网关与服务的完整调用链。")。
  • 声明方式二：就近注释标记：在图片行正下方添加 HTML 注释 <!-- @desc: 详细说明内容... -->。
  • 图解卡片渲染：博客解析引擎会自动将带有说明的图片转换为结构化图解卡片，并在图片下方附带图片内容说明面板与一键复制功能。
  • 全局搜索联动：图片说明文本会自动纳入全站全文搜索索引，通过关键词即可直接检索出包含对应图解说明的文章。

源代码：

6. 封面图片语法 ​

为了在主流 Markdown 编辑器与博客系统间兼具所见即所得的体验，博客支持专用的封面图片扩展语法。

  • 语法标记：使用标准 Markdown 图片语法，将替代文本 alt 指定为 cover、封面 或 banner，例如 ![cover](./assets/cover.png)。
  • 可选属性：封面为完全可选配置。未配置封面的文档直接由标题与元数据平滑过渡至正文。
  • 多源支持：既支持本地 ./assets/ 相对路径图片，也支持在线图床或网络 CDN 图片。
  • 主流编辑器兼容：在 Typora、Obsidian、VS Code 等主流编辑器中，直接渲染为常规大图，编辑与离线阅读所见即所得。
  • 博客专属排版次序：博客解析引擎会自动识别该标记，重构视觉层级为：文档标题 -> 文档元数据 -> 封面图片 -> 正文内容。
