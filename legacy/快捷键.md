## 输入法
+ ALT + 0215：输出 × 号

## JetBrains
+ 插件： 
    - translation：右键翻译
    - Lingma：通义灵码AI
    - Json helper：json格式化
+ 定位代码行号：`Ctrl+G`，行号:字符号
+ 替换字符：`Ctrl+R`
+ `.var` 可以快速给方法返回定义一个变量名
+ `sout` --> `System.out.println()`
+ `.for` 创建遍历的模板
+ 快捷键 `F2` 快速移动到有 error 或 warning
+ 快捷键 `Alt + Enter` 快速修复
+ 快捷键 `Ctrl + Shift + Alt + T` 快速重构代码（重构大量变量名）
+ 快捷键 `Ctrl + J` 查看所有代码模板
+ `Alt + ↑ / ↓` 快速移动
+ `/ + Enter` 快速创建 javadoc 注解
+ `Shift + F6` 快速重命名一个变量（一个变量的所有用到的变量名）
+ `Ctrl+ +/-` 快速展开/折叠代码块
