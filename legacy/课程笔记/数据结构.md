# 树
## 名词解释
+ 节点的度：一个节点含有子节点的个数。
+ 叶节点|终端节点：度为0的节点。
+ 分支节点|非终端节点：度不为0的节点。
+ 双亲节点|父节点：若一个节点有度（即有子节点），该节点为父节点。
+ 孩子节点|子节点：也就是拥有度的这些节点的下一层节点。
+ 兄弟节点：拥有相同父节点的子节点。
+ 树的度：孩子节点最多的度。
+ 节点的层次：从根节点开始从1开始算。
+ 树的高度|深度：树中节点的最大层次。
+ 节点的祖先：从根节点到该分支的所有节点。
+ 子孙：以某节点为根的子树中的任意节点。
+ 森林：由 m(m>0)棵互不相交的多棵树的集合称为森林

## 二叉树的四种遍历方式
+ 前序遍历
+ 中序遍历
+ 后序遍历
+ 层序遍历

## 树的分类
+ 普通二叉树：仅满足 “每个节点最多 2 个子节点”
+ 满二叉树：除叶子节点外，**所有节点均有 2 个子节点**；且叶子节点在同一层
+ 完全二叉树：按 “层序遍历” 填充节点，**中间无空缺**
+ 二叉搜索树：（BST，Binary Search Tree）也称二叉排序树，二叉查找树。可以为空；如果不为空，满足以下性质：（中序遍历之后为顺序结构） 
    - 非空左子树的所有键值小于其根结点的键值。
    - 非空右子树的所有键值大于其根结点的键值。
    - 左、右子树都是二叉搜索树。
+ AVL树：基于BST，任意节点的左右子树高度差不超过1
+ 红黑树：基于BST，每个节点额外存储了一个 color 字段 ("RED" or "BLACK")，用于确保树在插入和删除时保持平衡。
+ B树：多段查找树。每个结点的孩子数可以多于两个；且每一个结点处可以存储多个元素。
+ B+树：基于 B 树优化。仅**叶子节点存完整数据**；叶子节点按顺序双向链接。

## B树
性质：

+ 阶数为n时： 
    - 每个结点最多可以有n-1个关键字
    - 非根结点最少需要 `⌈n/2⌉-1` （天花板符号，向上取整）个关键字
    - 根结点可以有比非根结点更少的关键字，最少1个

## 折半查找判定树
+ 中序遍历为升序的顺序结构
+ 二分查找的规则，依次确定根结点
+ 举例：
    - (1+10)/2=5 根结点选5
    - (1 + 4) / 2 = 2 左子树根结点选2
    - (6 + 10) / 2 = 8 右子树根结点选8
    - ……
+ 解题过程：
    - 判断一棵二叉树是否是折半查找判定树。
    - 先用中序遍历，给每个结点赋值。
    - 再将两个连续的结点运算进行判定。
    - 两结点的值相加再除以二向上取整，如果为两个结点中较大的值即通过。
+ 先序序列为a,b,c,d的不同二叉树的个数是____。

根据二叉树前序遍历和中序遍历的递归算法中递归工作栈的状态变化得出：前序序列和中序序列的关系相当于以前序序列为入栈次序，以中序序列为出栈次序。因为前序序列和中序序列可以唯一地确定一棵二叉树，所以题意相当于“以序列a,b,c,d为入栈次序，则出栈序列的个数为？”

对于n个不同元素进栈，出栈序列的个数为：

$$ \frac{1}{n+1}C^n_{2n} $$

+ 非递归遍历一个平衡二叉树，使用栈方法。时间、空间复杂度为 $O(n)$ 。
