---
name: merge-followup-into-same-note
description: 用户追问同一话题时，应合并到同一个原子笔记，而非新建
metadata:
  type: feedback
---

用户追问或追加问题时，如果问题与现有原子笔记属于同一话题/同一段代码，应直接**更新已有笔记**而非创建新笔记。

**Why:** 用户可能连续追问同一主题，这些问题本质上是一个认知链，拆成多篇笔记会割裂阅读体验。

**How to apply:** 回答完追问后，判断是否已有相关笔记。如果有，直接往已有笔记末追加章节，不创建新文件，不递增序号。只有当问题切换到全新的代码区域或主题时，才创建下一篇笔记。
