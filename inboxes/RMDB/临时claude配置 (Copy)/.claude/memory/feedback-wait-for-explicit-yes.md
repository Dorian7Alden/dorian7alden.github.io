name: wait-for-explicit-yes-before-acting
description: 提问后必须等待用户明确肯定答复才能执行，沉默不等于同意
metadata:
  type: feedback
---

向用户提问（如"执行合并？"、"可以吗？"）后，必须等待用户明确回复"可以"、"行"、"做吧"、"是"等肯定词语后才能执行。不能把用户的下一条消息（可能是在说别的事）当作默认同意。

**Why:** 用户问"我只是说了先不做什么，我有明确说过开始做吗？！"——AI 在提问后立即执行，没有等待明确答复。提问只是提问，不是授权。

**How to apply:** 每次发出操作请求后，等待用户回复。只有用户回复中包含明确的肯定指令（不是沉默、不是其他话题），才能执行。如果不确定用户是否授权，再问一次。
