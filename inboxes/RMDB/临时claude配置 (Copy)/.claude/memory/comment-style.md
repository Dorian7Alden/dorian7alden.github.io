name: comment-style
description: 代码注释规范：中文注释，每个定义/声明处都要写注释
metadata:
  type: feedback
---

所有注释使用中文。每个常量定义、变量声明、类型别名、函数声明处都要写注释，说明其用途。复杂功能、复杂程序、复杂逻辑处也要写注释解释。

**Why:** 用户明确要求的编码规范，适用于整个 RMDB 项目。

**How to apply:** 编写或修改任何代码时，确保：
1. 每个 `static constexpr`、`extern`、`using` 等定义/声明处都有中文注释
2. 每个函数声明/定义处都有中文注释说明功能
3. 复杂算法、复杂逻辑、复杂功能处写注释解释
4. 不使用英文注释
