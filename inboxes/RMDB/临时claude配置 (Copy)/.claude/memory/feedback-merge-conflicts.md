description: 合并分支遇到冲突时必须由用户决定如何取舍，AI 不得自行解决
metadata:
  type: feedback
---

合并分支时如果遇到冲突，AI 必须：
1. 列出冲突文件和冲突内容
2. 说明每处冲突的来源（哪个分支引入了什么改动）
3. 等待用户明确指示如何取舍

不得自行选择保留哪一侧、修改冲突内容或使用 `--ours` / `--theirs` 策略。

**Why:** 用户强调合并时的冲突抉择涉及对代码意图的理解，只有作者本人才能做正确判断。AI 擅自解决可能引入错误或丢失有效代码。

**How to apply:** 执行 `git merge` 后如果输出包含 CONFLICT，立即停止，列出冲突详情和来源，等待用户指示。用户说如何解决就如何解决，不能替用户判断。
