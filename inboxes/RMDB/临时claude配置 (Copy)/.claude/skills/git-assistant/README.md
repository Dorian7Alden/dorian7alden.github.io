# git-assistant

Git 操作指导技能。当用户询问 git 操作或协作场景时触发，只提供指导和建议，不执行任何修改仓库的操作。

## 结构摘要

| 条目 | 用途 |
|------|------|
| `SKILL.md` | 技能定义，含触发条件 |
| `git-协作规范.md` | 团队 Git 协作规范（分支、提交消息、合并策略） |
| `git-协作场景模拟.md` | 常见协作场景和应对示例 |

## 本层规则

**此技能只能给建议，不执行 add/commit/push/merge 等操作。**
> **只读的原因**：Git 操作不可逆且影响团队，必须由用户亲自执行。AI 的职责是提供符合项目规范的指导。
