# RMDB 函数实现

实现函数或方法的标准流程。核心原则：思路先于代码，注释保留在代码中形成"思路→实现"的对应结构。

## 步骤 1: 了解上下文

- 读对应的 `.h` 头文件，理解函数签名、参数含义、返回值
- 读 `.cpp` 源文件，了解当前是空壳还是部分实现
- 确认依赖的上下游接口（调用链）

## 步骤 2: 写出注释步骤

在函数体内先用中文注释写出实现步骤，每条注释一个编号：

```cpp
int Foo::do_something(int a, int b) {
    // 1. 检查输入参数合法性
    // 2. 计算中间结果
    // 3. 更新内部状态
    // 4. 返回最终结果
}
```

要求：
- 步骤粒度适中，不要过细（避免"声明变量"、"调用 XX 函数"这种单句），也不要过粗（一个步骤包含太多事情）
- 复杂步骤下可以有子步骤
- 思路先于代码：先想清楚全貌再动手

## 步骤 3: 逐条实现

将每条注释转化为对应的实现代码，注释保留在上方：

```cpp
int Foo::do_something(int a, int b) {
    // 1. 检查输入参数合法性
    if (a < 0 || b < 0) {
        throw std::invalid_argument("参数必须为非负数");
    }

    // 2. 计算中间结果
    int result = a * multiplier_ + b;

    // 3. 更新内部状态
    last_result_ = result;

    // 4. 返回最终结果
    return result;
}
```

## 注释规范

实现过程中必须遵守以下注释规范：

1. **中文注释** — 所有注释必须用中文，不使用英文注释
2. **声明处必注释** — 每个常量定义、变量声明、类型别名、函数声明处都要写注释说明用途
3. **复杂处必注释** — 复杂算法、复杂逻辑、复杂功能处写注释解释
4. **注释保留** — 步骤注释不删除，保留在代码中形成"思路→实现"的对应结构

### 声明注释示例

```cpp
// 最大页面大小（字节）
static constexpr size_t kMaxPageSize = 65536;
// 磁盘管理器，负责所有文件操作
std::unique_ptr<DiskManager> disk_manager_;
// LRU 淘汰器，管理缓冲池页面置换
using LRUReplacer = Replacer<LRUPolicy>;
```

## 步骤 4: 自检

实现完成后确认：
- 每个步骤注释下方都有对应的实现代码
- 所有注释为中文
- 每个声明/定义处都有注释
- 异常路径有适当的错误处理
- 重新 review 一样，确保没有问题
