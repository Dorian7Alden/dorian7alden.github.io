# dev-doc

开发过程文档，记录讨论、设计决策、技术细节。由 `conversation-to-docs` 技能生成和维护。

## 结构摘要

| `code-explain/` | 源代码解释的原子笔记，每篇围绕一个具体问题 |
| `system-characteristics/` | 系统特性记录：参数边界、访问模式、资源粒度，供性能分析参考 |
| `performance-improve/` | 性能优化记录，每次优化的动机、手段、效果 |

## 本层规则

**文件命名：通用文档用编号前缀（00-xxx），任务相关文档用 task-<编号>-xxx。**
> **编号命名的原因**：用户偏好编号组织，编号反映阅读顺序或任务编号，便于快速定位。

**此目录由 conversation-to-docs 技能维护，手动编辑应遵循相同的命名和格式约定。**
> **统一入口的原因**：避免手动编辑和自动生成混用导致格式不一致。
