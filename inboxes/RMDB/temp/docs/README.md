# docs

项目文档目录，包含官方资料、题目描述、开发过程记录和工作流记录。

## 结构摘要

| 目录 | 用途 |
|------|------|
| `official-docs/` | 大赛官方提供的参考文档：环境配置、使用说明、项目结构等 |
| `tasks/` | 10 道在线评测题目的详细描述和子任务说明 |
| `temp-dev-doc/` | 临时的开发过程文档（备份）：代码讲解、系统特性、性能优化记录 |
| `workflow/` | 工作流记录：测评流程、提交策略、性能测试方法 |
| `task-conflict-analysis.md` | 10 道题目满分分支合并冲突分析报告 |

## 本层规则

**每个子目录必须有 README.md，形成渐进式披露。顶层只做索引，详细信息在子目录 README 中展开。**
> **分层的原因**：避免单文件信息过载，按需逐层深入。
