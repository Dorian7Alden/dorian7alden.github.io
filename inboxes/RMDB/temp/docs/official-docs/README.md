# official-docs

大赛官方提供的参考文档和资料。

## 结构摘要

| 文档 | 用途 |
|------|------|
| `RMDB使用文档.md` | RMDB 使用说明 |
| `RMDB环境配置文档.md` | 开发环境配置指南 |
| `RMDB项目结构.md` | 代码框架和模块结构详解 |
| `测试说明文档2026.md` | 测试框架和使用说明 |
| `决赛性能测试SQL示例.md` | 决赛性能测试的 SQL 参考 |
| `数据一致性检验规则.md` | 数据一致性校验规范 |

| `框架图.pdf` | 代码框架结构图 |

## 本层规则

**官方文档保持原样，不做修改。其中 `.md` 和 `.pdf` 为相同内容的两种格式，按需阅读。**
> **保留 PDF 的原因**：部分文档含图表，PDF 格式保留原始排版。
